# 1. Project Vision

## Mission
To make it fast, easy, and trustworthy for anyone in Ghana to find, hire, and manage skilled tradespeople.

## Vision
Build Africa's leading marketplace for skilled trades, beginning in Ghana and expanding across the continent.

Long-term goal:
Become the "Uber + Airbnb + Thumbtack" for skilled trade services.

# 8. Coding Standards

Always:

- Write readable code.
- Keep components reusable.
- Avoid duplicate logic.
- Use descriptive variable names.
- Keep files organized.
- Handle errors gracefully.

Development Rule:

One file at a time unless explicitly approved.

When debugging:

Explain the root cause before fixing.
